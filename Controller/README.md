# Muni Controller

키보드·클릭으로 강도와 페이스 타점을 고르거나, 트랙패드 스윙으로 샷을 만들어 MuniGolf에 보내는 Mac 앱입니다.
강도·페이스 모드는 두 개의 왕복 바를, 트랙패드 모드는 스윙 크기·템포·방향·컨택을 샷 값에 반영합니다.
기존 SC4 Muni Sender와 별도 앱이며, Sender의 개인 샷 파일을 읽거나 변경하지 않습니다.
‘트랙패드 스윙’ 옆의 ‘스윙캐디 연결’ 탭에서는 Bluetooth 검색부터 SC4 연결·등록과 실측 샷 전송까지 진행합니다.

## 스윙캐디 Bluetooth 연결

1. SC4 전원을 켜고 Mac 가까이에 둡니다. MySwingCaddie와 SC4 Shot Collector 등 다른 앱의 SC4 연결을 해제합니다.
2. ‘스윙캐디 연결’에서 ‘Bluetooth 검색’을 누릅니다. macOS가 요청하면 Bluetooth 접근을 허용합니다.
3. 발견된 SC4에서 ‘연결·등록’을 누릅니다. SC4 서비스와 샷 알림 구독을 확인한 뒤 등록 완료로 표시합니다.
4. 다음 실행부터 ‘등록된 스윙캐디 → 다시 연결’을 사용할 수 있습니다. 자동으로 기기를 검색하거나 연결하지 않습니다.
5. MuniGolf의 ‘연결 확인’ 후 이 탭에서 새 샷을 수신하면 한 번 자동 전송합니다. 다른 조작 탭에서는 SC4 샷을 저장만 합니다.

등록 해제는 이 앱의 기기 등록만 지웁니다. 샷 파일과 SC4 기기 기록은 유지합니다.
지원 대상은 기존 SC4 서비스입니다. 다른 서비스를 사용하는 SC4 Pro는 제외합니다.
연결 권한은 macOS가 처리합니다. 임의의 PIN이나 기기 ID 변경 명령을 보내지 않습니다.

실측 속도(m/s)는 mph로 변환하고 측정한 발사각·출발 방향·스핀을 사용합니다.
SC4에서 측정하지 않는 스핀축은 0°로 보내므로 실제 드로우·페이드 곡률을 재현한다고 보장하지 않습니다.
누락되거나 범위를 벗어난 필수 값은 가상 값으로 채우지 않고 원본만 저장합니다.
실측 샷에는 `IsMock=false`를 사용하며 클럽 데이터는 측정된 속도가 있는 경우에만 포함합니다. 가상 페이스 컨택을 붙이지 않습니다.

원본 패킷과 샷은 `~/Library/Application Support/Muni Controller/SC4/`에 추가 저장합니다.
전체 샷을 저장한 뒤 마지막 수신 응답을 보내고, 같은 기록을 재수신하거나 앱을 다시 실행해도 게임에 중복 전송하지 않습니다.
SC4 명령은 기기 정보 조회와 실시간 샷 수신 응답만 허용합니다. 기기 이력 읽기·삭제·설정 변경을 보내지 않습니다.
전송 중에 새 샷이 도착하면 그 샷은 저장만 하며, 이전 샷이나 실패한 샷을 나중에 자동 전송하지 않습니다.

## 2단계 강도·페이스 타점

1. 클럽·샷 타입·블로를 고르고 START 또는 Enter로 시작합니다.
2. **강도 바**가 1~110%를 계속 왕복합니다. Space 또는 바 클릭으로 강도를 확정합니다. 100~110%는 오버스윙 구간입니다.
3. **페이스 타점 바**가 계속 좌우로 왕복합니다. 다시 Space 또는 클릭으로 타점을 확정하면, 연결된 MuniGolf에 자동 전송합니다. 별도 전송 버튼은 없습니다.
4. 두 바 모두 입력 전까지 계속 움직입니다. 시간이 지났다고 자동으로 타격하거나 종료하지 않습니다.
5. 결과 뒤 Space/클릭 또는 START로 다음 스윙을 시작합니다. Esc, 앱 전환 또는 입력 방식 변경은 진행 중인 스윙을 취소합니다.

강도는 0.1% 단위로 잡습니다. 타점 바 속도는 잡은 강도에 따라 아래 기준점 사이에서 연속적으로 변합니다.

| 파워 기준점 | 타점 바 속도 | 편도 이동 시간 | 난이도 |
|---|---:|---:|---|
| 30% | 0.5배 | 3.6초 | 쉬움 |
| 50% | 0.75배 | 2.4초 | 보통 |
| 70% | 1.0배 | 1.8초 | 어려움 |
| 100% | 1.5배 | 1.2초 | 매우 어려움 |
| 110% | 1.75배 | 약 1.03초 | 오버스윙 |

힘이 커질수록 페이스 컨택 바가 연속적으로 빨라집니다. 100% 이상에서도 속도가 계속 증가하며, 중앙 판정 구간의 너비는 고정입니다.

| 중앙 오차 | 판정 | 결과 |
|---|---|---|
| 0~2% (2% 포함) | Perfect | 정타 |
| 2% 초과~5% | Excellent | 거의 정타 |
| 5% 초과~10% | Good | 약간 빗맞음 |
| 10% 초과~20% 미만 | Fair | 거리 손실 |
| 20% 이상 | Miss | 큰 거리·방향 손실 |

오차는 바 **전체 너비**에 대한 중앙과의 거리입니다. Perfect 구간은 중앙 ±2%로 모든 파워에서 고정입니다.
화면 갱신 위치가 아닌 키보드·마우스 이벤트 시각으로 강도와 타점을 잡습니다.
누르고 있는 키의 자동 반복, 더블클릭의 두 번째 클릭 및 단계 전환 후 0.12초 이내의 중복 입력은 무시합니다.
입력 칸에 글을 쓰는 중에는 Space를 스윙으로 가로채지 않습니다.
‘좌우 시작 방향 랜덤’을 끄면 왼쪽→오른쪽, 켜면 스윙마다 시작 방향을 무작위로 고릅니다.
시작·진행 방향과 관계없이, 바의 **멈춘 위치**는 클럽 페이스의 같은 위치를 뜻합니다.

Perfect는 선택한 파워만큼의 기준 거리를 목표로 합니다. 오차가 커질수록 볼 속도와 거리가 줄어듭니다.
중앙은 스위트스폿, 왼쪽은 힐, 오른쪽은 토입니다. 페이스 왼쪽 10% 이내의 극힐은 슬라이스, 오른쪽 10% 이내의 극토는 훅으로 연결합니다.
오른손 기준 힐 쪽은 양의 스핀축, 토 쪽은 음의 스핀축으로 계산하며, 이 규칙은 왕복 방향이 바뀌어도 같습니다.
판정은 게임 규칙에 따른 가상 컨택입니다. 이 가로 바만으로 뒤땅·얇은 타격까지 추정하지는 않습니다.
확정한 Miss는 손실이 큰 미스샷으로 보냅니다. 입력 없이 기다리는 동안에는 공 데이터를 보내지 않습니다.

## 샷 타입과 블로

스트레이트·드로우·페이드·로우·하이·스팅어, 로우/하이 드로우·페이드를 선택할 수 있습니다.
구질은 발사 방향·스핀축·클럽 패스에, 탄도는 발사각·스핀·참고 거리에 반영합니다.
극힐/극토의 큰 미스는 선택한 드로우·페이드보다 우선해 슬라이스/훅 성향을 유지합니다.

블로는 기본·다운블로·어퍼블로 중 선택합니다.
다운블로는 계산된 스핀을 **20% 증가**, 어퍼블로는 **20% 감소**시키고 AngleOfAttack도 함께 바꿉니다.
이는 컨트롤러의 명시적인 게임 규칙이며 실제 스핀을 측정하거나 모든 골프 상황의 스핀을 예측하는 모델은 아닙니다.
샷 타입과 블로는 두 입력 방식에 모두 적용하며, 강도 바를 시작할 때 설정을 고정합니다. 퍼팅에는 구질·블로 스핀 보정을 적용하지 않습니다.

## 실행과 게임 전송

1. MuniGolf에서 연습장 또는 코스를 엽니다.
2. `dist/Muni Controller.app`을 실행합니다. 기본 주소는 `127.0.0.1:9210`입니다.
3. 클럽을 선택합니다. 게임에서도 같은 클럽을 선택합니다.
4. ‘연결 확인’을 눌러 서버 응답을 확인합니다. 화면에 ‘타점 확정 시 자동 전송’이 표시됩니다.
5. ‘파워·타이밍’에서 START→Space/클릭으로 강도→Space/클릭으로 페이스 타점을 정합니다. **타점 확정 즉시 한 번 자동 전송**합니다.
6. 또는 ‘트랙패드 스윙’에서 가운데 공을 누른 채 아래로 당긴 뒤, 공 쪽으로 밀고 공 위에서 놓으면 자동 전송합니다.
7. 연결 전에는 결과만 확인하며 전송하지 않습니다. 연결 확인은 이전 결과를 보내지 않고 **다음 스윙부터** 적용합니다.

공을 크게 벗어나면 헛스윙입니다. 헛스윙은 공의 비행 데이터로 보내지 않습니다.
트랙패드는 정확히 공에 돌아오면 정타, 좌우는 토·힐, 앞뒤는 얇은 타격·뒤땅으로 판정합니다.
Esc, 패드 초기화 또는 앱 전환으로 진행 중인 스윙을 취소합니다.
‘컨택 연습 예시’는 연결 중에도 전송하지 않습니다. 연결은 유지하며 다음에 직접 조작한 스윙은 자동 전송합니다.
앱을 실행할 때마다 ‘연결 확인’을 먼저 합니다.

## 클럽과 거리

드라이버·3W·4H·4~9번 아이언·PW·GW·SW·LW·퍼터를 제공합니다.
클럽별 100% 스윙 기준 거리, **로프트**와 스핀을 바꾸고 저장할 수 있습니다.
거리 표시는 yd/m 선택, 퍼팅은 항상 ft입니다.
목표 방향, 페이스 방향, 스윙 길이 민감도도 조절할 수 있습니다.

로프트 기본값은 캘러웨이 공식 제품 사양을 사용합니다. 조절식 모델은 아래 값을 선택했습니다.

| 클럽 | 모델 | 기본 로프트 |
|---|---|---:|
| 드라이버 | [Elyte](https://www.callawaygolf.com/golf-clubs/drivers/drivers-2025-elyte.html) | 10.5° |
| 3W | [Elyte](https://www.callawaygolf.com/golf-clubs/fairway-woods/fwoods-2025-elyte.html) | 15° |
| 4H | [Elyte](https://www.callawaygolf.com/golf-clubs/hybrids/hybrids-2025-elyte.html) | 22° |
| 4 / 5 / 6 / 7 / 8 / 9 / PW | [Apex Ai200](https://www.callawaygolf.com/golf-clubs/irons/irons-2024-apex-ai200.html) | 21 / 23 / 26 / 30 / 34 / 38 / 43° |
| GW / SW / LW | [Opus](https://www.callawaygolf.com/cg/golf-clubs/wedges/wedges-2024-opus-black.html) | 50 / 56 / 60° |
| 퍼터 | [Odyssey Ai-ONE #1 CH](https://odyssey.callawaygolf.com/putters/ai-one/spr5714589.html) | 3° |

처음 업데이트할 때 이전 클럽 설정을 별도 보관하고 로프트·기준 발사각만 새 기준으로 전환합니다. 저장한 기준 거리와 스핀은 유지합니다.
‘기본값’은 선택한 클럽을 이 사양으로 되돌립니다. 캘러웨이는 여러 모델·옵션을 제공하므로 실제 클럽에 맞게 로프트를 수정할 수 있습니다.

가상 스윙의 힘은 볼 속도에, 로프트는 발사각에 반영하며 두 조작 방식에 같은 발사각 계산을 사용합니다.
클럽별 전달 모델에서 100% 발사각을 추정하고 `0.75 + 0.25 × √파워`를 적용합니다.
이 전달 모델·기준 거리·속도·스핀은 앱의 추정값이며 캘러웨이의 측정 데이터가 아닙니다.
결과의 ‘참고 최고높이’는 전송할 볼 속도·발사각·스핀으로 계산합니다. 중력과 공기저항, 간단한 백스핀 양력 및 시간에 따른 스핀 감쇠를 반영한 해수면·무풍 추정입니다.
같은 로프트에서는 힘이 클수록 높아지고, 같은 속도에서는 로프트가 높을수록 발사각과 높이가 커집니다. 퍼팅은 높이 0으로 유지합니다.
높이를 게임에 강제로 지정하지 않으며 MuniGolf가 전달된 발사 조건으로 자체 탄도를 계산합니다.

표시 거리는 컨트롤러의 힘 곡선으로 계산한 **참고값**입니다. MuniGolf의 기상·지형·볼 물리와 일치하도록 보정한 값이 아닙니다.
실제 샷의 거리는 게임이 전송된 볼 속도·발사각·스핀으로 계산합니다. Controller는 계산한 참고 거리를 `CarryDistance`로 강제하지 않습니다.
컨택 및 타격 위치는 조작을 골프 컨택으로 대응시킨 가상 값이며, 실제 클럽·공 센서의 측정값이 아닙니다.

## 전송 항목과 범위

TCP Open Connect JSON을 사용합니다.

| 객체 | 전송 항목 |
|---|---|
| BallData | Speed(mph), HLA, VLA, TotalSpin(rpm), SpinAxis |
| ClubData | Speed, SpeedAtImpact(mph), AngleOfAttack, FaceToTarget, Loft, Path, HorizontalFaceImpact, VerticalFaceImpact |
| ShotDataOptions | ContainsBallData/ContainsClubData=true, IsMock=true |

컨택은 볼 속도·탄도·스핀축에 반영합니다. 페이스 타격 위치도 수치로 함께 보냅니다.
설치된 LaunchMonitorConnect 2026.11.2.0의 정적 확인에 따라 타격 위치는 mm이며, 가로 음수=힐/양수=토, 세로 음수=낮은 타점/양수=높은 타점입니다.
패드에서 앞에 놓으면 얇은 타격(낮은 타점), 뒤에 놓으면 뒤땅(높은 타점)으로 대응시킵니다.
`Lie`와 `ClosureRate`처럼 이 조작으로 정하지 않은 값은 보내지 않습니다.

‘정타/뒤땅’ 같은 문자 라벨은 Controller 화면에서 보여 줍니다. 게임에는 지원된 숫자 항목으로 표현합니다.
MuniGolf가 추가 클럽/타점 정보를 화면이나 내부 물리에 사용하는지는 실제 게임에서 확인하지 않았습니다.
클럽 종류를 게임에 설정하는 클라이언트 명령은 공개 Open Connect v1 문서에 없으므로 게임 클럽 선택은 직접 합니다.

서버의 Code 200 응답을 받아야 전송 완료로 표시합니다.
샷 번호는 시도마다 증가하며 같은 스윙을 중복 전송하거나 자동 재시도하지 않습니다.
응답이 없거나 연결이 끊기면 게임에서 결과를 확인하고 ‘연결 확인’을 다시 누릅니다. 샷 없는 하트비트만 전송하며, 실패한 샷을 다시 보내지 않습니다.

공식 자료: [Open Connect v1](https://gsprogolf.com/GSProConnectV1.html), [MuniGolf](https://munigolfsim.com/), [AppKit 마우스 이벤트](https://developer.apple.com/library/archive/documentation/Cocoa/Conceptual/EventOverview/HandlingMouseEvents/HandlingMouseEvents.html).
키보드 판정에는 [NSEvent.timestamp](https://developer.apple.com/documentation/appkit/nsevent/timestamp)를 사용합니다. 시스템 시간은 타이머와 앱 내 이벤트 간 경과 시간 계산에만 쓰며 원시 가동 시간은 전송하지 않습니다.
설치된 브리지는 실행 없이 정적으로 확인했으며, 그 프로그램의 코드를 포함하거나 변경하지 않습니다.

## 빌드와 검증

Apple Silicon Mac, macOS 13 이상에서 별도 패키지 없이 빌드합니다.

```sh
zsh build-controller.sh
zsh test-controller.sh
zsh test-controller.sh --network
```

검증은 가상 궤적, 임시 설정과 격리된 로컬 테스트 서버를 사용합니다. 실제 MuniGolf에는 테스트 샷을 보내지 않습니다.
SC4 프레임 분할 수신·체크섬·내구성 저장·중복 방지·단위 변환은 합성 패킷으로 검증합니다. 실제 SC4와의 Bluetooth 연결과 실제 게임 탄도는 별도 현장 확인이 필요합니다.
설정·SC4 기기 등록은 앱의 전용 UserDefaults에 저장하며, 가상 스윙 궤적과 최근 전송 표시는 세션 동안만 유지합니다. SC4 원본·샷 파일은 재실행 후에도 보존합니다.
